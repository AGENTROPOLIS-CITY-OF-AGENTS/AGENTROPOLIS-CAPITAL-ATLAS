# Capital Atlas Rust Finance Boundary

Capital Atlas keeps Next.js/TypeScript and Cloudflare-native components for discovery, intake, dashboards, document workflows, and public presentation.

Rust becomes mandatory for production finance-critical services, including:

- deterministic financial projections and amortization calculations
- eligibility/scoring engines when outputs drive consequential automated actions
- capital-stack calculations and underwriting kernels
- signed/canonical decision receipts
- payment, wallet, settlement, or x402 integration
- high-integrity audit-event generation

Funding discovery and recommendation remain advisory evidence, not authority. Applications, payments, commitments, investments, loans, or other consequential financial actions must cross explicit policy/human approval gates.

When deployed Cloudflare-first, Rust cores may compile to WebAssembly where appropriate or run as separately isolated services. Do not force Rust into UI code merely to increase language share.
